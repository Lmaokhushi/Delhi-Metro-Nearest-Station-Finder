# 🚇 Delhi Metro Nearest Station Finder

A beginner Python project that finds the nearest Delhi Metro station to your live location.

## How it works
1. Downloads metro station data from OpenStreetMap
2. Gets your live location through your browser
3. Calculates distances with the Haversine formula
4. Shows the nearest stations on an interactive map

## How to run
1. Install the libraries: `pip install pandas requests folium`
2. Open `delhi_metro_simple.ipynb` in VS Code or Jupyter
3. Run the cells from top to bottom
